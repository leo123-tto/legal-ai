## 第1章 公司基本信息与主体资格

### 1.1 调查目的
确认目标公司依法设立并有效存续，具备从事其业务活动的合法主体资格。

### 1.2 调查要点清单

**工商登记信息**：
- [ ] 营业执照（正、副本）：核对公司名称、统一社会信用代码、类型、住所、法定代表人、注册资本、成立日期、营业期限、经营范围
- [ ] 营业执照记载事项与实际经营情况是否一致
- [ ] 营业执照是否在有效期内，是否通过最近一次年检/年报公示

**设立与章程**：
- [ ] 设立批准文件（外资企业、特殊行业等需审批设立的）
- [ ] 公司章程（现行有效版本）
- [ ] 历次章程修正案
- [ ] 章程内容是否符合《公司法》强制性规定
- [ ] 章程中是否存在特殊条款（如限制股权转让的特别约定、一票否决权、优先购买权等）

**变更登记**：
- [ ] 历次变更登记材料（名称、住所、法定代表人、注册资本、经营范围、股东等变更）
- [ ] 变更登记程序是否合法合规（是否经过必要的内部决策程序）
- [ ] 工商登记信息与公司内部文件（章程、决议等）是否一致

**公司治理基础文件**：
- [ ] 股东会、董事会、监事会（监事）议事规则
- [ ] 议事规则是否符合《公司法》和章程规定

**印章与信用**：
- [ ] 公司印章备案情况（公章、合同章、财务章、法人章等）
- [ ] 印章管理制度
- [ ] 企业信用信息公示报告（近一个月内）
- [ ] 是否存在经营异常名录记录
- [ ] 是否存在严重违法失信记录

### 1.3 常见风险点（红旗标志）🚩

| 风险事项 | 风险等级 | 说明 |
|---------|---------|------|
| 营业执照过期未续 | 🔴 高 | 主体资格存疑 |
| 经营范围不含实际主营业务 | 🟡 中 | 超范围经营风险 |
| 章程限制股权转让且未获豁免 | 🔴 高 | 直接影响交易可行性 |
| 存在经营异常名录记录 | 🟡 中 | 信用瑕疵，可能影响业务 |
| 工商登记与实际不符 | 🟡 中 | 需核实并整改 |
| 设立程序有瑕疵 | 🔴 高 | 可能影响公司有效存续 |
| 章程中存在不利特殊条款 | 🟡 中 | 需评估对交易的影响 |
| 严重违法失信记录 | 🔴 高 | 影响公司经营和信用 |

### 1.4 标准发现语言模板

**主体资格确认**：
> 经查阅目标公司的营业执照（统一社会信用代码：XXXXXXXXXXXXXXXXXX），目标公司系于[日期]在[登记机关]登记设立的[有限责任公司/股份有限公司]，注册资本为人民币[金额]万元，法定代表人为[姓名]，营业期限自[日期]至[日期/长期]，经营范围为[经营范围]。截至本报告基准日，目标公司的营业执照处于有效状态。

**章程确认**：
> 经查阅目标公司提供的公司章程（[日期]版），该章程系经目标公司全体股东于[日期]签署/经股东会决议通过，章程主要条款符合《中华人民共和国公司法》的相关规定。[如有特殊条款：]章程第[X]条规定了[特殊条款内容]，本律师提请委托人关注该等条款对本次交易的影响。

**变更登记确认**：
> 经核查目标公司的工商变更登记档案，目标公司自设立以来共进行了[X]次变更登记，主要变更事项包括：[列举主要变更]。上述变更均已办理工商变更登记手续。[如有问题：]但本律师注意到，[具体问题]。

**信用信息确认**：
> 经查询国家企业信用信息公示系统（查询日期：[日期]），目标公司不存在/存在经营异常名录记录，不存在/存在严重违法失信记录。[如存在：]具体情况如下：[列明]。

> 💡 **元典工商数据辅助**：建议拉取 `get_enterprise_base_info`（工商基本信息）、`enterprise_change_info`（历次变更）、`enterprise_abnormal_operation`（经营异常）、`enterprise_serious_illegal`（严重违法失信）子命令数据辅助本章撰写。
> 详见 [enterprise-endpoints-summary.md](chineselaw/enterprise-endpoints-summary.md)

## 第2章 股权结构与股东信息

### 2.1 调查目的
全面了解目标公司的股权结构，确认各股东的出资情况和股权权属状态，识别股权上的权利负担。

### 2.2 调查要点清单

**股东与出资**：
- [ ] 最新股东名册
- [ ] 各股东出资证明书
- [ ] 各股东主体资格证明（法人股东：营业执照；自然人股东：身份证）
- [ ] 验资报告及银行进账单等出资凭证
- [ ] 各股东是否已按章程约定足额缴纳出资
- [ ] 出资方式（货币/实物/知识产权/土地使用权等）是否合法合规
- [ ] 非货币出资是否已办理财产权转移手续

**股权变动**：
- [ ] 历次股权转让协议
- [ ] 历次增资扩股协议
- [ ] 对应的股东会决议、章程修正案
- [ ] 股权转让/增资的定价依据
- [ ] 股权变动是否取得了其他股东的同意/放弃优先购买权声明
- [ ] 股权变动是否存在国有资产审批、外资审批等特殊程序要求
- [ ] 历次股权变动是否均已办理工商变更登记

**特殊安排**：
- [ ] 是否存在股权代持（隐名持股）安排
- [ ] 代持协议的主要条款
- [ ] 是否存在一致行动协议
- [ ] 是否存在投票权委托
- [ ] 是否存在股东间的对赌协议/业绩承诺

**权利限制**：
- [ ] 股权质押情况（质押登记信息）
- [ ] 股权冻结情况（法院执行信息）
- [ ] 其他权利限制（如股权转让限制协议）

### 2.3 常见风险点（红旗标志）🚩

| 风险事项 | 风险等级 | 说明 |
|---------|---------|------|
| 出资未实缴或未足额缴纳 | 🔴 高 | 股东有补缴义务，影响公司资产 |
| 存在股权代持 | 🔴 高 | 隐名股东可能主张权利，影响交易确定性 |
| 股权存在质押 | 🔴 高 | 处分受限，需质权人同意 |
| 股权被法院冻结 | 🔴 高 | 无法转让 |
| 历史股权转让未取得优先购买权放弃声明 | 🟡 中 | 可能被主张无效 |
| 非货币出资未办理权属转移 | 🔴 高 | 出资瑕疵 |
| 存在对赌协议 | 🟡 中 | 需评估对新股东的影响 |
| 工商登记与实际持股不一致 | 🟡 中 | 存在权属争议风险 |

### 2.4 标准发现语言模板

**股权结构确认**：
> 经查阅目标公司的营业执照、公司章程及工商登记信息，截至本报告基准日，目标公司的股权结构如下：
>
> | 股东名称 | 出资额（万元） | 持股比例 | 出资方式 | 认缴/实缴 |
> |---------|--------------|---------|---------|----------|
>
> 目标公司股东共[X]名，注册资本人民币[金额]万元。

**出资确认**：
> 根据[验资报告/银行进账单/其他凭证]，截至[日期]，[股东名称]已实际缴纳出资人民币[金额]万元，占其认缴出资额的[X]%。[如未足额缴纳：]尚有人民币[金额]万元认缴出资未缴纳，按照公司章程约定应于[日期]前缴足。

**股权代持发现**：
> 经查阅目标公司提供的资料及访谈，本律师注意到[名义股东]与[实际出资人]之间存在股权代持安排，具体情况如下：[说明代持协议的主要内容]。本律师提请委托人特别关注：(1) 代持协议的法律效力；(2) 实际出资人是否可能主张显名化；(3) 代持关系对本次交易的影响。

> 💡 **元典工商数据辅助**：建议拉取 `get_enterprise_base_info`（股东/出资信息）、`enterprise_pledge`（股权质押）、`enterprise_frozen_equity`（股权冻结）子命令数据辅助本章撰写。
> 详见 [enterprise-endpoints-summary.md](chineselaw/enterprise-endpoints-summary.md)

## 第3章 公司治理与组织结构

### 3.1 调查目的
评估目标公司治理结构的合规性和有效性，确认决策程序的合法性。

### 3.2 调查要点清单

**组织架构**：
- [ ] 公司组织结构图
- [ ] 各部门职责说明
- [ ] 分支机构（分公司）设置情况
- [ ] 子公司设置情况

**董事、监事、高管**：
- [ ] 现任董事、监事、高级管理人员名单
- [ ] 上述人员简历及身份证明
- [ ] 任职的合法性（选举/聘任程序、任职资格）
- [ ] 是否存在《公司法》规定的任职禁止情形
- [ ] 董监高的薪酬安排

**三会运作**：
- [ ] 历次股东会会议通知、议案、签到表、决议、会议记录
- [ ] 历次董事会会议通知、议案、签到表、决议、会议记录
- [ ] 历次监事会（监事）会议通知、决议、会议记录
- [ ] 会议召集程序是否合法（通知时间、通知方式）
- [ ] 表决程序是否合法（表决权比例、回避等）
- [ ] 决议内容是否合法（是否存在应经特别决议而未经特别决议的事项）
- [ ] 是否存在决议被撤销或确认无效的情况

**内部制度**：
- [ ] 内部管理制度汇编
- [ ] 财务管理制度
- [ ] 印章管理制度
- [ ] 关联交易管理制度
- [ ] 内部审计制度（如有）

### 3.3 常见风险点（红旗标志）🚩

| 风险事项 | 风险等级 | 说明 |
|---------|---------|------|
| 股东会/董事会决议程序违法 | 🔴 高 | 决议可能被撤销或认定无效 |
| 三会会议记录缺失 | 🟡 中 | 治理规范性不足 |
| 董监高存在任职禁止情形 | 🔴 高 | 任职违法 |
| 无内部管理制度 | 🟡 中 | 管理风险，影响估值 |
| 重大事项未经法定程序 | 🔴 高 | 法律效力存疑 |
| 实际控制人通过非正式途径控制公司 | 🟡 中 | 治理透明度不足 |

### 3.4 标准发现语言模板

**组织架构确认**：
> 根据目标公司提供的组织结构图及相关资料，目标公司设有[部门列举]等部门。目标公司[无/有]分支机构，[无/有]对外投资设立的子公司。

**三会运作确认**：
> 经查阅目标公司提供的股东会/董事会/监事会会议文件，自[起始日期]至本报告基准日，目标公司共召开股东会[X]次、董事会[X]次、监事会（监事检查）[X]次。经抽查，上述会议的召集程序、表决方式和决议内容总体符合/不符合《公司法》及公司章程的规定。[如有问题：]本律师注意到以下问题：[具体问题]。

> 💡 **元典工商数据辅助**：建议拉取 `get_enterprise_base_info`（高管/分支机构信息）、`enterprise_change_info`（历次组织结构变更）子命令数据辅助本章撰写。
> 详见 [enterprise-endpoints-summary.md](chineselaw/enterprise-endpoints-summary.md)

## 第4章 核心资产

### 4.1 调查目的
核实目标公司主要资产的真实性、合法性、完整性，确认是否存在权利负担。

### 4.2 调查要点清单

**不动产**：
- [ ] 土地使用权证/房屋所有权证/不动产权证书
- [ ] 土地出让合同/划拨决定书
- [ ] 房屋买卖合同及付款凭证
- [ ] 不动产登记信息查询结果
- [ ] 不动产是否存在抵押登记
- [ ] 不动产是否存在查封
- [ ] 不动产是否存在租赁（买卖不破租赁）
- [ ] 租赁房产：租赁合同、出租方权属证明、租赁期限、续租条件
- [ ] 土地用途是否合法，是否存在闲置土地风险
- [ ] 建设工程是否取得完整的规划、施工、验收手续

**动产**：
- [ ] 主要生产经营设备清单
- [ ] 设备购买合同及发票
- [ ] 车辆行驶证、登记证
- [ ] 动产是否存在抵押或质押
- [ ] 设备状态、折旧情况

**知识产权**：
- [ ] 商标注册证（注册号、类别、有效期）
- [ ] 专利证书（专利号、类型、有效期）
- [ ] 著作权登记证书
- [ ] 域名注册信息
- [ ] 知识产权许可使用合同（被许可/许可他人）
- [ ] 知识产权转让合同
- [ ] 知识产权是否存在质押
- [ ] 是否存在知识产权侵权纠纷或被侵权情况
- [ ] 核心技术/商业秘密的保护措施

### 4.3 常见风险点（红旗标志）🚩

| 风险事项 | 风险等级 | 说明 |
|---------|---------|------|
| 不动产存在抵押且未告知 | 🔴 高 | 权利负担影响资产价值和处分 |
| 不动产被法院查封 | 🔴 高 | 资产处分受限 |
| 核心不动产系租赁而非自有 | 🟡 中 | 经营稳定性风险 |
| 土地用途与实际使用不符 | 🔴 高 | 违法用地风险 |
| 建设手续不完整 | 🔴 高 | 违建风险 |
| 核心知识产权非公司所有 | 🔴 高 | 影响核心竞争力和估值 |
| 商标/专利即将到期未续展 | 🟡 中 | 权利丧失风险 |
| 存在知识产权侵权诉讼 | 🟡 中 | 赔偿风险 |
| 核心设备老旧、折旧严重 | 🟢 低 | 影响资产估值 |

### 4.4 标准发现语言模板

**不动产确认**：
> 经查阅目标公司提供的不动产权属证明文件及不动产登记信息，目标公司名下共有[X]处不动产，基本情况如下：
>
> | 序号 | 权证编号 | 坐落 | 面积 | 用途 | 取得方式 | 权利限制 |
> |------|---------|------|------|------|---------|---------|
>
> [如存在抵押：]其中，位于[地址]的[不动产]已设定抵押登记，抵押权人为[名称]，担保债权金额为人民币[金额]元，抵押期限至[日期]。

**知识产权确认**：
> 经查阅目标公司提供的知识产权权属证明文件，截至本报告基准日，目标公司名下拥有的知识产权情况如下：
>
> **商标**：注册商标[X]件。[列表说明]
> **专利**：专利[X]项，其中发明专利[X]项、实用新型[X]项、外观设计[X]项。[列表说明]
> **著作权**：软件著作权[X]项。[列表说明]

> 💡 **元典工商数据辅助**：建议拉取 `enterprise_brand`（商标）、`enterprise_patent`（专利）、`enterprise_soft_right`（软著）、`enterprise_works_right`（作品著作权）、`enterprise_out_invest`（对外投资）子命令数据辅助本章撰写。

## 第5章 业务经营与合同管理

### 5.1 调查目的
了解目标公司的主营业务模式、核心合同履行情况及业务资质的合法合规性。

### 5.2 调查要点清单

**业务概况**：
- [ ] 主营业务介绍、商业模式说明
- [ ] 收入构成分析（各业务板块占比）
- [ ] 行业地位及市场竞争格局
- [ ] 商业计划书、年度经营计划及总结报告（近三年）

**核心合同**：
- [ ] 主要销售/服务合同（前十大客户合同）
- [ ] 主要采购合同（前十大供应商合同）
- [ ] 重大合作协议（合资、联营、战略合作等）
- [ ] 特许经营合同、加盟合同（如有）
- [ ] 合同的签署主体、金额、期限、主要条款
- [ ] 合同的履行情况（是否存在违约、争议）
- [ ] 合同中的限制性条款（排他、竞业、不竞争等）
- [ ] 合同中的控制权变更条款（Change of Control）

**客户与供应商**：
- [ ] 主要客户名单及交易金额（近三年）
- [ ] 主要供应商名单及交易金额（近三年）
- [ ] 客户/供应商集中度分析
- [ ] 是否存在关联方客户/供应商

**业务资质**：
- [ ] 行业许可证、资质证书
- [ ] 特种行业经营许可
- [ ] 进出口经营权（如适用）
- [ ] 各类资质的有效期及年检情况
- [ ] 是否存在无证经营或超范围经营

### 5.3 常见风险点（红旗标志）🚩

| 风险事项 | 风险等级 | 说明 |
|---------|---------|------|
| 缺少必要的行业许可/资质 | 🔴 高 | 违法经营风险 |
| 核心合同含控制权变更终止条款 | 🔴 高 | 交易可能导致合同终止 |
