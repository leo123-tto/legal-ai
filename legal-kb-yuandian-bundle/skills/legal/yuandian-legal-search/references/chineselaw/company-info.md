# 元典企业名称检索接口

接口用途：根据企业名称、曾用名或股票简称检索候选企业，并返回候选企业详情字段。适合在用户只提供公司名称时锁定主体。

## 接口要点

| 项 | 值 |
|---|---|
| HTTP Method | `GET` |
| URL | `https://open.chineselaw.com/open/rh_company_info` |
| 鉴权 | Header `X-API-Key: <key>` |
| 入参 | `name`（必填）+ `num`（可选） |
| 返回 | `data` 为列表，每条 schema 与企业详情接口基本一致 |

## 使用方式

本包不提供单独 CLI，推荐在 agent 中通过 `yd_ref` 调用：

```python
import sys
sys.path.insert(0, "scripts")
import yd_ref

items = yd_ref.get_company_info(name="目标公司名称", num=10)
```

如果只知道模糊名称，优先使用主体定位接口：

```python
candidates = yd_ref.enterprise_search("目标公司名称", top_k=5)
```

## 与企业详情接口的关系

| 维度 | 企业名称检索 | 企业详情 |
|---|---|---|
| 入参 | `name` | `id` 或 `tyshxydm` |
| 返回 | 候选列表 | 单个主体 |
| 适用 | 名称起步、重名核验、简称检索 | 已确认主体后的精准查询 |

推荐流程：

1. 用户只给公司名：先查候选。
2. 根据企业名称、统一社会信用代码、法定代表人、注册地址、成立日期确认主体。
3. 记录目标主体的 `id` 或 `tyshxydm`。
4. 再调用企业详情、聚合总览、涉诉执行等接口。

## 写入底稿规范

由名称检索取得的数据，必须说明检索词和主体选择过程：

> 经查阅元典开放平台「企业名称检索」接口（检索词：「XXX」，命中 N 条候选，选定第 K 条作为目标企业；调用时间 YYYY-MM-DD HH:MM，原始数据见 `raw/chineselaw/...`），目标公司基本工商登记信息如下：……

多条候选未选定时，禁止直接将列表第 1 条写入底稿。

## 失败与降级

- 名称过短或过宽时，可能返回异常或低质量结果；应换更完整名称、曾用名或股票简称。
- 多次调用同一名称变体可能重复消耗积分，先用较准确的公司名称。
- 元典未命中时，记录“元典库未命中”，转人工查询国家企业信用信息公示系统或用户提供的证照材料。
